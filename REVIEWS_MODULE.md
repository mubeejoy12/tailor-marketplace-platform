# Reviews & Ratings Module

## Overview

The Reviews & Ratings module enables customers to leave structured feedback on delivered orders. Ratings are aggregated into a live average score per tailor, visible across the marketplace.

---

## Architecture

```
Customer (browser)
    │
    ▼
ReviewService.ts          ← frontend service
    │
    ▼  POST /api/reviews
ReviewController.java     ← Spring REST controller
    │
    ▼
ReviewService.java        ← business logic + validation
    │
    ├── ReviewRepository.java      ← JPA queries
    ├── OrderRepository.java       ← verify DELIVERED status
    ├── UserRepository.java        ← resolve reviewer name
    └── TailorProfileRepository.java  ← recalculate avg rating
```

---

## Database Schema

```sql
CREATE TABLE reviews (
    id          BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    user_id     BIGINT        NOT NULL,                 -- FK → users.id
    tailor_id   BIGINT        NOT NULL,                 -- FK → tailors.id
    order_id    BIGINT        NOT NULL UNIQUE,          -- one review per order
    rating      INT           NOT NULL CHECK (rating BETWEEN 1 AND 5),
    comment     TEXT,
    created_at  TIMESTAMP     NOT NULL DEFAULT now()
);

-- Indexes for fast lookup
CREATE INDEX idx_review_tailor_id  ON reviews (tailor_id);
CREATE INDEX idx_review_user_id    ON reviews (user_id);
CREATE INDEX idx_review_created_at ON reviews (created_at);
```

## API Endpoints

### POST `/api/reviews`
Submit a review for a delivered order.

**Auth:** Bearer token required  
**Request body:**
```json
{
  "userId":   9,
  "tailorId": 3,
  "orderId":  4,
  "rating":   5,
  "comment":  "Excellent craftsmanship!"
}
```

**Response (201 Created):**
```json
{
  "id":           1,
  "userId":       9,
  "reviewerName": "Mubarak",
  "tailorId":     3,
  "orderId":      4,
  "rating":       5,
  "comment":      "Excellent craftsmanship!",
  "createdAt":    "2026-06-03T12:00:00"
}
```

**Business rules enforced:**
- Order must belong to the requesting user
- Order status must be `DELIVERED`
- One review per order (unique constraint on `order_id`)
- Rating must be 1–5 (validated via `@Min` / `@Max`)
- After save: tailor's average rating is recalculated and persisted

---

### GET `/api/reviews/tailor/{tailorId}`
Fetch all reviews for a tailor, newest first.

**Auth:** Not required  
**Response (200 OK):** Array of ReviewResponse

---

### GET `/api/reviews/order/{orderId}/exists`
Check whether a specific order has already been reviewed.

**Auth:** Bearer token required  
**Response:**
```json
{ "reviewed": true }
```

## Frontend Flow

### Customer submitting a review

1. Customer opens **Order Tracking** (`/orders/{id}`)
2. If `orderStatus === "DELIVERED"` and not yet reviewed → `ReviewForm` appears
3. Customer picks 1–5 stars with the interactive `StarRating` component
4. Customer types an optional comment
5. `submitReview()` from `reviewService.ts` → `POST /api/reviews`
6. On success: form replaced with "Review submitted — thank you!" banner

### Order list CTA

- In **My Orders** (`/orders`), every DELIVERED order shows a ⭐ **Leave Review** link
- Clicking navigates to the order tracking page where the form is shown

### Tailor profile

- **Tailor Detail** (`/tailors/{id}`) shows:
  - Average star rating + review count in the booking sidebar
  - Full scrollable list of reviews (reviewer name, stars, comment, date)
  - "No reviews yet — be the first!" empty state

### Tailor dashboard

- **Dashboard** (`/dashboard`) now shows:
  - Rating stat card (avg + review count) alongside order status counts
  - **Latest Reviews** section — most recent 5 reviews with avatar, name, stars, comment snippet

## Business Rules Summary

| Rule | Enforcement |
|------|-------------|
| Only DELIVERED orders can be reviewed | `ReviewService.java` check on `order.orderStatus` |
| One review per order | `UNIQUE` DB constraint on `order_id` + `existsByOrderId()` pre-check |
| Rating must be 1–5 | `@Min(1)` / `@Max(5)` on `ReviewRequest.rating` |
| Review must belong to order owner | `order.getUserId().equals(req.getUserId())` check |
| Tailor rating auto-updates | `recalculateTailorRating()` called after every successful save |

---

## Rating Recalculation

After each review is saved, `ReviewService.recalculateTailorRating()`:
1. Fetches all reviews for that tailor
2. Computes the arithmetic mean of all ratings
3. Rounds to 1 decimal place (`HALF_UP`)
4. Persists the new value to `tailors.rating`

This means the rating shown everywhere (tailor cards, detail page, dashboard) is always up-to-date.
